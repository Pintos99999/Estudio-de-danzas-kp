Una sola vez: conectar para publicar

Para que los cambios lleguen a la página hace falta una clave de GitHub. Se pide una sola vez y queda guardada en este navegador.

  1. Entrá a github.com → crear clave.
  2. En Repository access elegí Only select repositories y marcá Estudio-de-danzas-kp.
  3. En Permissions → Repository permissions, buscá Contents y ponelo en Read and write.
  4. Generá la clave y pegala acá abajo.

La clave queda sólo en este navegador y únicamente permite cambiar los archivos de este sitio. Si estás en una computadora prestada, mejor no la guardes: usá Descargar archivo desde Inicio.
